خريطة الدرس

إيه اللي هنغطيه النهاردة؟

1 float — وليه بيسبب مشكلة اختفاء الـ parent
2 overflow — لما المحتوى يبقى أكبر من الصندوق

4 z-index — مين بيظهر فوق مين

التفاف العناصر

float

القيم: none (الافتراضي) | left | right — العنصر بيطلع من الـ normal flow والباقي بيلتف حواليه

style.css
1.parent { background: lightblue; } 2.child { 3 width:100px; height:100px; 4 float: left; 5} 6/* fix: clear لأي عنصر بعد الـ floats */ 7.clear { clear: both; }

الحد الأحمر = مكان الـ parent؛ خلفيته اختفت لأن ارتفاعه بقى 0
لما الأطفال (children) يبقوا float، الـ parent بيفقد ارتفاعه فتختفي خلفيته (collapsing parent)
أي عنصر (زي p) جاي بعد الـ floats بيتلف بجانبهم مش تحتهم
الحل: عنصر بعد الـ floats بخاصية clear: left | right | both

لما المحتوى يزيد

overflow

إيه اللي بيحصل لو المحتوى (زي كلمة طويلة) أكبر من مساحة الـ div؟

style.css
1.box { 2 overflow: auto; /* visible|hidden|scroll|auto */ 3 overflow-x: hidden; 4 overflow-y: auto; 5}
overflow-y: auto — مرّر بالماوس 👇
سطر واحد طويل جدًا ممكن يطلع برة الصندوق لو overflow: visible،
لكن مع auto بيظهر scrollbar بس لما المحتوى فعلاً زايد عن حجم الصندوق، وتقدر تعمل scroll تشوف الباقي هنا تحت.
القيمةالمعنى
visible (افتراضي)المحتوى بيطلع برة حدود الصندوق عادي
hiddenأي جزء زايد بيتقطع ومش بيبان خالص
scrollscrollbar بيظهر دايمًا حتى لو المحتوى مش زايد
autoscrollbar بيظهر بس لو المحتوى فعلاً زايد

overflow: scroll

الفرق بين scroll و auto

scroll بيظهر الـ scrollbar دايمًا حتى لو المحتوى مش زايد، أما auto بيظهر بس لما المحتوى فعلاً زايد

overflow-y: auto (نفس المحتوى)
سطرين بس من النص، ومفيش scrollbar خالص لأن المحتوى أصلاً مش زايد عن الصندوق.
style.css
1.box { overflow-y: scroll; } /* scrollbar ثابت */ 2.box2 { overflow-y: auto; } /* حسب الحاجة */

overflow: hidden

hidden مقابل visible

hidden بيقطع أي جزء زايد عن حدود الصندوق نهائيًا (مفيش طريقة توصله بالـ scroll)

overflow: visible (الافتراضي)
نص طويل جدًا بيطلع برة حدود المربع الأزرق وبيتراكب فوق اللي حواليه
overflow: hidden
نص طويل جدًا بيتقطع عند حدود المربع الأحمر ومش بيبان الباقي خالص

استخدام شائع لـ hidden: قص الحواف الزايدة من صورة، أو عمل clearfix لمشكلة الـ float

تحديد الأماكن

position

من غير position غير static، خصائص top/bottom/left/right مالهاش أي تأثير. قبل ما تحرك عنصر اسأل: مكانه الأصلي هيفضل ولا هيتحرر؟ وهيتحرك بالنسبة لمين؟

النوعمكانه الأصليبيتحرك بالنسبة لمين
relativeمحجوز (بيفضل ياخد مكانه)بالنسبة لمكانه هو نفسه
absoluteبيتحرر تمامًاأقرب parent عنده position (وإلا الشاشة)
fixedبيتحرر تمامًاالـ viewport (الشاشة) مباشرة
stickyrelative لحد نقطة معينةparent بتاعه، وبعدين يـ"يلزق" زي fixed
absolute: عرضه fit-content، ولازم تحط للـ parent position: relative عشان يتحرك بالنسبة له مش للشاشة كلها
fixed: مفيد لعناصر زي أيقونة واتساب — تفضل ثابتة حتى مع الـ scroll
sticky: لازم تحدد top/bottom/left/right على الأقل، وبيختفي مع نهاية الـ parent بتاعه

position: relative

relative

بيتحرك بالنسبة لمكانه هو نفسه، ومكانه الأصلي بيفضل محجوز (فراغ باين مكانه القديم)

style.css
1.two { 2 position: relative; 3 top: 30px; 4 left: 20px; 5}

absolute

بيتحرك بالنسبة لأقرب parent عنده position، ولازم تحط للـ parent position: relative

style.css
1.parent { position: relative; } 2.child { 3 position: absolute; 4 bottom: 0; right: 0; 5}

position: fixed

fixed

بيتحرك بالنسبة للـ viewport مباشرة — بيفضل مكانه حتى لو عملت scroll في الصفحة

style.css

ترتيب الطبقات

z-index

لازم العنصر يكون positioned (غير static) عشان z-index يشتغل — الرقم الأكبر بيظهر فوق

style.css
1div { position: absolute; width:120px; height:120px; } 2.two { top:30px; left:30px; } 3.three { top:60px; left:60px; z-index:50; }
z-index: 50 على المربع الأخضر 👇

و z-index: -1 بتخلي العنصر يختفي ورا كل حاجة تانية

فخ شائع ⚠️

z-index من غير position

z-index مبيشتغلش خالص على عنصر static (بدون position) — الترتيب هيفضل حسب ترتيب الظهور في الـ HTML بس

style.css
1.box { 2 /* من غير position */ 3 z-index: 999; /* بلا فايدة! */ 4}
z-index:999 على الأزرق، بس من غير position 👇

الأزرق فضل تحت الأحمر رغم z-index:999 — لازم position (relative/absolute/fixed/sticky) الأول

z-index سالب

z-index: -1

بيخلي العنصر يختفي ورا كل حاجة تانية — حتى ورا خلفية الصندوق نفسه

style.css
1.hidden-box { 2 position: absolute; 3 z-index: -1; 4}
قبل / بعد إضافة z-index:-1 👇
قبل: z-index:0
بعد: z-index:-1

في الصندوق التاني، البنفسجي مختفي بالكامل ورا خلفية أبوه — طريقة شائعة لإخفاء عنصر بصريًا وهو لسه موجود فعليًا في الـ DOM
